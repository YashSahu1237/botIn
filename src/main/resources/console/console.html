The decision tables — what is configured, without running anything

Read straight from the .dmn files. Hit policy is FIRST: the first row whose every non-empty cell matches produces the answer, and nothing below it is consulted — row order is logic, not formatting. An empty cell means the column does not matter for that row. The sentence under each row is the comment above it in the file, so the rule and its reason cannot drift apart.

The acceptance run — every case checks itself

This is not a walkthrough. Each case asserts what it expected and reports a failure rather than hiding it, so a red row here is the system working. Run one to talk about it; run them all for the verdict — the whole run happens every time, because the cases somebody would skip with a room watching are the ones worth seeing. The same list drives tools/demo-run.sh, so the terminal and this page cannot disagree.
